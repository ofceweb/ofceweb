# Version de quarto-ife installée dans un projet

Version de quarto-ife installée dans un projet

## Usage

``` r
quarto_ife_installed_version(path = ".")
```

## Arguments

- path:

  Racine du projet Quarto.

## Value

La version lue dans \`\_extensions/ofceweb/ife/\_extension.yml\`, ou
\`NULL\` si le fichier est absent ou illisible.
