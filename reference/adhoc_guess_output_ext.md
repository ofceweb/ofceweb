# Guess a format's output extension from its name

Guess a format's output extension from its name

## Usage

``` r
adhoc_guess_output_ext(name)
```

## Arguments

- name:

  \`\[character(1)\]\` Format name (e.g. \`"wp-pdf"\`,
  \`"pres-revealjs"\`).

## Value

\`\[character(1)\]\` The guessed extension, \`".html"\` by default.
