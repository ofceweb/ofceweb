# Rescanne les pages d'un document de travail

Wrapper autour de \[rescan_site()\] pour les dépôts WP. Le comportement
est identique.

## Usage

``` r
rescan_wp(path = ".", icon = "newspaper")
```

## Arguments

- path:

  Chemin vers la racine du dépôt. Défaut \`"."\`.

- icon:

  Icône bootstrap utilisée pour chaque entrée. Défaut \`"newspaper"\`.
