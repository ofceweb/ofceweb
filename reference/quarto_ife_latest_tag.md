# Plus haute version publiée parmi des étiquettes

Plus haute version publiée parmi des étiquettes

## Usage

``` r
quarto_ife_latest_tag(tags)
```

## Arguments

- tags:

  Noms d'étiquettes. Seules celles de forme \`vX.Y.Z\` comptent.

## Value

La plus haute version, sans le \`v\` (\`"0.10.0"\`). Erreur si aucune
étiquette n'a cette forme.
